# Jordan R. Hall, PhD

Applied mathematician and data leader working at the intersection of quantitative methods, software, and business strategy.

I currently lead data strategy at Westport Properties, where my work spans revenue management, data analytics, data science, data systems, technical leadership, and applied AI. Most of my professional work lives in proprietary systems, so this GitHub is a mix of research code, selected personal projects, and ongoing technical work.

### Selected work

* **[ASTARS](https://github.com/jordanrhall/ASTARS)** — derivative-free optimization for noisy convex functions using active subspaces; developed from my PhD research.
* **[summix_py](https://github.com/jordanrhall/summix_py)** — Python implementation of the Summix method for detecting and adjusting for population structure in genetic summary data.
* **[fantasy-recap](https://github.com/jordanrhall/fantasy-recap)** — a small modern Python project for generating fantasy football recaps, with testing and CI.

### Current focus

I am gradually modernizing older research repositories and using this space to publish small, complete examples of the engineering practices I use and continue to develop: data systems, testing, CI/CD, APIs, software design, and modern Python tooling.

My academic work includes applied optimization, uncertainty quantification, and statistical genetics.
